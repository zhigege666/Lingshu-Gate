# 版本更新检查

进入控制台“系统设置 → 版本更新”时，会检查 `zhigege666/Lingshu-Gate` 最新的正式 GitHub Release，也支持手动检查。结果包含当前运行的后端版本、最新标签、发布日期、更新说明和发行链接。

## 配置 GitHub 检查代理

更新检查可以使用已有的、已启用的 HTTP 或 HTTPS 代理配置：

1. 在“系统设置 → 网络与依赖”中创建或检查代理配置。
2. 打开“系统设置 → 版本更新”。
3. 选择代理配置并保存。检查器会固定所选配置的版本。
4. 选择“直连 GitHub”即可关闭更新检查代理。

代理设置只作用于 GitHub Release API 请求，不会改变 Git 拉取、npm/Python 仓库、MCP 调用或 Gate 的其他网络流量。凭据继续保存在现有加密凭据库中，更新设置 API 不会返回凭据原文。当前检查器不支持 SOCKS 代理。

## 安装边界

版本发现会自动执行，但应用更新仍由部署环境负责。Gate Core 按设计不持有 Docker Engine Socket，不能直接替换自身容器。请使用正式发行资产或部署平台更新镜像/程序，然后检查 `/readyz` 和实际运行版本。本功能不会静默重启 Gate，也不会绕过正常启动迁移流程或自行回滚部署。
