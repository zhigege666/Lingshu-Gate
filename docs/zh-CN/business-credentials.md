# 业务凭据与浏览器账号

[English](../business-credentials.md) · [配置](configuration.md) · [文档索引](README.md)

业务凭据用于在 Gate 中维护网站账号，明确允许哪些 MCP 实例使用，再让 Agent 通过引用操作，避免在聊天中传递密码。本指南介绍 `agent_browser` 适配器。绑定是额外的使用限制，不会自动发布工具，也不会扩大调用者已有的 MCP 权限。

## 选择合适的凭据类型

| 凭据类型 | 适用位置 |
| --- | --- |
| 共享服务凭据 | 通过现有凭据引用注入服务启动环境变量、共享 HTTP Header。 |
| 我的服务凭据 | 向符合条件的 MCP 实例所声明的个人槽位注入下游 HTTP Header。 |
| 业务凭据 | 网站账号、环境与业务角色标签、明确的实例绑定，以及 agent-browser 密码库中的版本化副本。 |

业务凭据不会把 HTTP Header 槽位改造成浏览器账号。OAuth 授权、访问令牌和刷新令牌仍走各自的授权流程。其他 MCP 产品需要具有已审查契约的适配器，任意工具不能自行解析业务凭据引用。

## 准备浏览器实例

使用专门的、可信的官方 agent-browser MCP 实例。启动时应同时开放浏览器工具和 `state` 工具组，例如：

~~~text
agent-browser mcp --tools core,state
~~~

适配器检查实际发现的保存、登录、删除和导航工具契约。其中，登录工具必须支持 `session` 和 `noNavigate`。默认 `core` 工具组不包含 auth 工具。兼容性检查失败时，核对实际安装版本与发现结果；工具名称相同并不足以证明兼容。

仍需在 Gate 中按正常流程审核分类并发布工具。调用者必须已具有相关 MCP 工具权限，添加业务凭据绑定不会替代这些授权。

管理员还须确保实例自行启动独立浏览器、保护本地存储，并且没有继承共享 CDP 连接、复用浏览器 profile、恢复状态、未经审查的 provider 或插件。绑定检查可以识别 manifest 中显式声明的部分覆盖配置，但 Gate 无法检查远端机器上的所有配置文件与继承设置。

首批适配器不支持声明了个人下游 HTTP Header 槽位（`user_credentials`）的浏览器目标。此类 Header 可能把不同 Gate 用户路由到不同的远端密码库或浏览器域，管理员收到的保存或关闭回执不能证明其他用户目标上的结果。请使用具有单一、已审查目标身份的专用实例。

**添加业务凭据绑定会为整个 MCP 实例启用凭据托管限制。** 经 Gate 调用该实例的其他用户也受到相同限制。需要完整浏览器调试能力时，使用另一个实例。删除最后一条凭据或绑定不会重新开放原始密码库工具。

## 录入账号并选择目标

1. 在相应的凭据页面打开业务账号区域。仅自己管理和使用的账号选择个人范围；需要向指定用户或 Gate 角色提供使用权的账号选择共享范围。
2. 填写清晰的名称，例如“测试环境医生”，以及环境、业务角色、登录地址、用户名和密码。业务角色用于描述网站账号，不会赋予 Gate 中的授权角色。
3. 共享凭据需要明确选择允许使用的 Gate 用户或角色。接收者列表为空不表示向所有人开放。
4. 常规登录表单可先不填写用户名、密码、提交按钮的选择器。只有站点实际需要时才配置相应控件。
5. 保存后，接口显示用户名掩码及配置状态，不回显已保存的密码。编辑时将用户名、密码留空表示保留原值；不能把掩码当作新凭据提交。
6. 为需要的 MCP 实例分别添加绑定。核对实例 ID，不能只看机器显示名。每个绑定分别记录同步状态。
7. 同步选中的绑定，回读其状态与已同步版本。其他目标也分别执行并核对结果。

仅通过可信的 HTTPS Gate 入口或本机回环连接录入秘密。网站登录地址默认要求 HTTPS；遗留 HTTP 站点需要显式确认允许 HTTP，这不会放宽 Gate 管理连接的保护要求。HTTP 登录会使账号密码在该网站的网络连接上失去 TLS 保护。

登录地址必须是完整 HTTP(S) 地址，不能包含嵌入式用户名密码或查询参数。支持 `#/login` 这样的路由片段；包含 `?`、`=` 或不以 `/` 开头的片段会被拒绝。不要把密码或令牌写入地址、名称、环境、角色标签、选择器、manifest 或聊天消息。

## 让 Agent 使用账号登录

通过 Gate 选择已绑定实例的 `agent_browser_auth_login` 工具。使用页面给出的凭据引用，并明确提供本轮逻辑会话：

~~~json
{
  "name": "gate:<credential-id>",
  "session": "task-demo"
}
~~~

上面仅包含工具参数。目标 MCP 实例需要单独选择，不要向该参数对象加入 `server_id`。将 `<credential-id>` 替换为实际 ID。显示名称方便识别账号，引用用于准确定位。

可以这样给 Agent 下指令：

> 使用“测试环境医生”凭据，在选定浏览器实例的 `task-demo` 会话中登录，再检查页面是否已经进入应用的登录状态。

Gate 会在使用节点副本前检查账号、调用者、目标绑定、当前版本和工具契约。它打开配置的登录页，再使用原生登录操作，在填写凭据前验证来源。调用者不能覆盖登录地址或添加任意 CLI 参数。

**“登录动作已执行”不等于网站认证成功。** 原生操作会填写并提交表单；网站随后仍可能拒绝密码、要求验证码或进入额外验证步骤。使用允许的浏览器工具检查页面状态。此适配器不会自动验证站点中的账号身份，也不会自动完成 MFA 流程。

后续操作沿用同一个逻辑会话。例如调用 `agent_browser_snapshot`：

~~~json
{
  "session": "task-demo",
  "interactive": true,
  "compact": true
}
~~~

Gate 将逻辑会话映射到与调用者和目标关联的内部会话，并绑定到选定的凭据。切换账号或业务角色时使用新的逻辑会话。凭据版本或绑定修订变化后，已有会话不能继续执行浏览器操作；关闭旧会话，完成需要的同步后再使用新会话。这也适用于绑定停用后重新启用，以及重复执行同步的情况。

首批适配器允许已审查的导航、表单操作、等待、文本或快照读取及关闭会话工具。直接 `open` 的地址须与配置的登录地址同源。网页链接或浏览器历史仍可能跳转到其他站点，这不会授权 Gate 向新来源填写凭据。

可以读取宿主机、导出浏览器状态、执行任意 JavaScript 或改变浏览器运行方式的工具，在凭据托管实例上不可用。包括原始密码库管理、`eval`、读取输入值或 HTML、导出 cookies/storage/state、网络抓包、文件上传下载、截图、批量执行、插件、CDP 连接及全局会话操作。未知工具和未审查的参数也会拒绝。这些限制属于适配器边界，即使较宽的 MCP 令牌原本允许相应工具，也不能绕过。

首批适配器不接受以 `-` 开头、会传给原生 CLI 的字符串参数，包括选择器、表单文本、选项值及保存的用户名。这类数据可能被 CLI 当作进程选项处理。保存的密码通过 stdin 传递，不受此项限制。Gate 会明确拒绝不支持的值，不会擅自改写其内容。

## 理解同步状态

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| `pending` | 当前版本尚未获得该绑定的成功同步确认。 | 对选定实例执行同步。 |
| `synced` | Gate 收到与记录版本对应的预期成功回执。 | 使用前核对已同步版本与当前版本一致。 |
| `failed` | 操作失败，但远端仍可能保留旧副本或部分更新后的副本。 | 解决提示的问题，再重试相应操作。 |
| `unknown` | Gate 无法确认结果，例如超时或响应中断。 | 按“远端可能存在副本”处理，通过 Gate 重试同步或清理。 |
| `deleted` | Gate 已收到该绑定的远端密码库条目删除确认。 | 只有需要继续使用时才重新同步。 |

编辑账号会生成新版本，并使绑定回到待同步状态。保存账号不会自动宣称所有节点已经更新；需要对目标分别执行同步。基于旧版本或旧绑定修订的操作会被拒绝，请重新读取记录后再操作。

同步成功表示配置的目标接受了保存操作，不代表 Gate 独立检查了节点磁盘，也不代表网站认可该密码。如果删除回执丢失，空的密码库列表也不足以证明清理完成；应保留待核对记录，直到能够确认清理结果。

**升级已绑定目标、修改其 manifest 或工具契约之前，先停用受影响的绑定，删除各远端副本，关闭受管浏览器会话，再移除绑定。** 随后修改目标并重新创建已复核的绑定。首批适配器固定原始目标与工具契约，不会为了登录或清理而自动接受变化后的目标。如果目标已经变更，可行时先恢复原已审查配置，完成清理后再变更。新目标上的成功操作不能作为旧目标已清理的证明。

## 分别处理停用、清理和关闭

| 操作 | 实际作用 | 不包含的效果 |
| --- | --- | --- |
| 停用凭据或绑定 | 阻止通过该绑定继续进行授权使用。 | 不会删除节点已经保存的密码，也不会撤销网站会话。 |
| 删除节点副本 | 通过适配器受控调用，删除该绑定的密码库条目。 | 不会使已经打开的浏览器自动退出网站。 |
| 关闭浏览器会话 | 关闭选定的受管浏览器会话。 | 不会撤销网站签发的全部会话。 |
| 删除 Gate 记录 | 在要求的远端副本清理完成后，删除本地加密记录。 | 不能替代网站侧的账号停用或会话撤销。 |

不再使用账号时，先停用，分别清理各节点副本，再单独关闭曾使用该账号的浏览器会话。远端清理未确认的记录会被保留；节点离线不会因为账号停用就变成“已清理”。完成要求的清理后再删除 Gate 记录。

在账号的绑定视图中展开“浏览器会话”，可以查看记录的会话状态并逐个关闭。`unknown` 表示仍需核对或清理，不代表浏览器从未打开。收到关闭确认后，页面显示浏览器已关闭，同时保留“网站退出状态未验证”的说明。

要关闭本轮逻辑会话，调用选定实例的 `agent_browser_close`：

~~~json
{
  "session": "task-demo"
}
~~~

原生 `all` 参数禁止使用。不要用全局关闭终止无关用户的工作。如果需要撤销网站范围内的登录状态，还须通过网站自身的会话管理或账号撤销机制处理。

## 安全与恢复边界

Gate 对业务用户名和密码进行静态加密，秘密不进入 MCP manifest，管理 API 返回安全元数据。受控保存、删除、登录操作只返回有限的状态信息。对于当前凭据绑定的浏览器会话，返回前还会对文本中的当前秘密及支持的编码形式进行脱敏；这是一层附加保护，不能保证识别网站对秘密进行的任意变换。

受管浏览器响应根据已审查的动作结果重新构造，不包含原始 CLI stdout/stderr，也不进入 Gate 的短期 `gate_result_read` 缓存。停用凭据会阻止新的受控调用，但无法收回已经交付给调用者的信息。

目标浏览器需要接收并填写真实密码。因此，目标宿主机管理员以及浏览器信任边界内运行的代码可能接触它。此适配器无法抵御恶意目标主机、恶意站点脚本、直接读取密码库，或经过其他网关绕开控制的访问。应使用专门的可信目标实例和可信登录来源。

agent-browser 密码库按操作系统用户存放，并不按浏览器 session 隔离。多个 Gate 实例共用同一操作系统用户或密码库，不属于此适配器的隔离保证范围。会话命名不能替代 OS 或容器隔离。本流程防止通过当前 Gate 实例发生误用和越权调用，不宣称提供面向互不信任用户的通用沙箱。

备份 Gate 数据库时，应同时备份受保护的凭据密钥。业务凭据密钥位于 `<data-dir>/business-credentials/credential.key`，密文保存在 Gate 数据库中。远端 agent-browser 密码库有独立的密钥和生命周期。丢失任一存储的密钥，都可能导致相应密文无法恢复。备份应放在仓库之外，并禁止浏览器内容访问。

安装与部署参见[开始使用](getting-started.md)和[配置](configuration.md)。上游契约参见官方 agent-browser [命令](https://agent-browser.dev/commands)、[安全](https://agent-browser.dev/security)及[会话](https://agent-browser.dev/sessions)文档。MCP 传输层授权另见 [MCP 授权规范](https://modelcontextprotocol.io/specification/2025-11-25/basic/authorization)。
