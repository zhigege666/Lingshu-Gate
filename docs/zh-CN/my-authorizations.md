# 我的授权

[English](../my-authorizations.md) · [内置 OAuth](builtin-oauth.md)

本指南描述当前开发源码，不表示已发布、部署或通过真实客户端验收。

## 统一个人入口

**我的授权**统一展示个人 Gate API 令牌、Gate OAuth 授权和外部提供方授权。认证方式作为每条记录的属性；底层凭据、协议和撤销目标保持独立。旧个人令牌书签进入统一页面并筛选 API 令牌。撤销只作用于对应来源的具体记录。各来源读取失败分别提示，部分加载的列表不能表示完整总数。

通过“新增授权”创建 API 令牌。OAuth 授权仍从客户端的真实授权流程产生。API 令牌明文仅在创建成功响应和一次性展示中出现，列表不能重新取回。调整范围及配额要求有效的本人 Console 会话和 `credentials.manage.self`。

## MCP 范围

每个业务 MCP 明确选择“不授权”“持续授权”或“指定工具”。持续授权分为只读和读写；读写包括未来发布的写工具。批选当前全部工具仍属于快照，不表示持续授权。同一条授权对同一服务不能同时使用持续和指定工具模式。

Gate API 令牌的独立范围与 Gate 业务 OAuth 已实现持续授权。后续工具只有在分类有效发布，且符合本人当前资源权限和功能 scope 时才自动纳入。未发布工具不可用，只读持续策略不会获得写工具。工具变更使分类失效期间拒绝访问；重新审核发布后，持续策略按当前读写级别重新判断，指定工具快照仍需明确重新确认。

服务策略绑定 MCP 生命周期身份。删除重建服务或替换信任目标后，不能因为复用相同 ID 或名称而继承旧授权。纯展示更名和保留信任身份的普通升级保留持续意图。API 令牌的指定工具快照也绑定服务身份。分类、发现、授权和部署仍是独立操作。

已有指定工具 OAuth 授权保留原快照，不静默转为持续模式。没有独立策略的旧 API 令牌继续“跟随账号资源权限”，保留原有继承行为，也不伪造调用配额。本人可以明确转换为独立 MCP 范围；独立范围为空表示没有业务 MCP 访问。编辑器不提供返回跟随账号模式的入口。功能控制权限与业务 MCP 范围分别管理。

外部提供方授权保留现有提供方及本地 allowlist 合同，不提供 MCP 持续授权。单独启用的 `/mcp/manage` 保留固定管理工具与精确目标合同，不订阅业务 MCP。

## 工具发现

列表“工具发现”列可打开对应授权的居中设置弹窗，直接选择“按需发现”或“完整工具列表”。**新旧业务授权均默认按需**；每条 API 令牌、Gate 业务 OAuth 或外部 OAuth 本地授权独立保存。管理资源保留固定工具。按需模式提供六个默认发现/调用/实例会话入口、可选有权固定工具，以及启用预算后的结果读取入口；完整模式直接列出当前有权工具；两种模式使用相同权限校验，均不扩大授权。

客户端设置只保存名称和接入地址，复制的配置不含 `tool_mode`。旧浏览器中保存的模式会在生成配置时移除。旧 URL 的 `tool_mode` 和 `X-Gate-Tool-Mode` 请求头均忽略，统一采用该授权设置；切换后须刷新客户端工具目录或重新连接。保存经过本人预览确认、CSRF、版本和原子审计；结果未知先刷新核对，禁止盲目重放。该设置不修改全局规则或 MCP 客户端插件配置，也不决定 MCP 客户端优先选择哪一个入口。

## 可编辑配额与安全保存

新业务授权默认**每分钟 6000 次、并发 100**。可编辑范围分别为整数 **1–10000** 和 **1–100**。已有记录回填实际数值，打开编辑器不覆盖为默认值。旧 API 令牌在明确设置前显示配额未设置。本人确认的 API 令牌和业务 OAuth 编辑器允许调高、调低配额，也支持只改配额。旧的只缩小 OAuth 操作保留原合同；修改配额不延长期限，也不扩大 OAuth scopes。

预览展示准确目标、策略变化、工具增减、未来写权限及前后配额。预览不授予权限。保存要求本人明确确认、当前权限重检、版本/目录/目标绑定、单次确认、修订 CAS 和原子脱敏审计。审计失败整体回滚。仅修改配额会保留已失效的指定工具快照与服务绑定，不会重新批准它们。保存结果未知时保留草稿，先读取实际状态后再写入；不能为了找回丢失的明文盲目重复创建。

运行权限取当前账号/资源权限、令牌或授权策略、有效已发布分类及功能 scope 的交集。Gate OAuth 还取客户端、grant、JWT 和令牌族 scopes 的交集。修改配额不清零已消耗的频次计数。降低并发不取消已派发调用，后续准入使用新上限。业务调用按 API 令牌 ID 或 OAuth grant ID 跨 MCP 共用预算，读取目录不等于执行工具。计数仍限单 Core 进程，进程重启会重置。SQLite 要求单写入者/Core；默认值不表示已测得的吞吐能力。

## 目录与验证限制

API 令牌新建/编辑目录目前支持最多 **5000 个工具、100 个 MCP** 的完整候选响应。新建超限明确失败，不静默截断。当大账号的无关目录超过此界限时，已有小范围令牌可读取有界原范围，返回 `catalog_complete=false`、`scope_editable=false`，仅调整配额。更大规模 API 令牌候选分页尚未实现。保存/有效范围继续有界，超限失败关闭。

Console 遵循 [UI 交互约束](ui-interaction-contract.md)：紧凑表格、标签左控件右、可访问的模式单选、不重复页面介绍，异常或帮助按上下文出现。某来源读取失败不能显示成完整空列表。

Gate 在后续请求重新解析授权，并在排队后派发前重检。它不会推送替换客户端工具目录，也不会扩大客户端 OAuth 授权。客户端可能缓存目录，需要主动刷新。真实提供方/ChatGPT 接入、客户端缓存刷新、部署及生产容量需分别验收；源码和合成测试不能证明这些结果。

## 发现偏好保存

工具发现编辑器还可管理最多 20 个固定项及可选纯文本结果预算。发现方式、固定项和预算共用一次版本绑定的审核与原子保存；切换模式保留其他草稿字段，目录读取失败不会当成空选择。冲突后先刷新再确认。偏好不改变凭据范围或到期时间。具体限制和分组会话要求见[固定工具与结果预算](on-demand-tools.md#固定工具与结果预算)。
