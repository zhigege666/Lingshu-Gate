# 我的授权

[English](../my-authorizations.md) · [内置 OAuth](builtin-oauth.md)

本指南描述当前开发源码，不表示已发布、部署或通过真实客户端验收。

## 统一个人入口

**我的授权**统一展示个人 Gate API 令牌、Gate OAuth 授权和外部提供方授权。认证方式作为每条记录的属性；底层凭据、协议和撤销目标保持独立。旧个人令牌书签进入统一页面并筛选 API 令牌。撤销只作用于对应来源的具体记录。各来源读取失败分别提示，部分加载的列表不能表示完整总数。

通过主按钮“创建 API 令牌”直接打开表单；“其他接入方式”提供 OAuth 指引与外部提供方授权入口。OAuth 授权仍从客户端的真实授权流程产生。API 令牌明文仅在创建成功响应和一次性展示中出现，列表不能重新取回。调整范围及配额要求有效的本人 Console 会话和 `credentials.manage.self`。

## 功能权限

API 令牌编辑器通过 **MCP 范围**、**功能权限**和**调用限制**三个标签页编辑同一份草稿。MCP 清单每行直接展示四种范围；选择“指定工具”或点击已选工具数量，即可展开精确工具选择；收起、搜索、翻页和切换标签不会提交或清除修改。刷新保留草稿及已失效选择。明确选择 MCP 范围时，会同时补齐该范围必需且本人当前可授予的读写功能权限；已有令牌扩权时会先列出新增项。手工取消必需权限时会显示冲突。新建和已有令牌都可选择跟随账号或独立范围。切换时在本地保留非当前模式的独立草稿，只提交当前模式的数据。保存仍使用后台预览和确认票据，仅扩大已有权限时额外显示差异确认。

在 API 令牌编辑器中选择“功能权限”标签，可核对完整可选范围。权限分组按阅读顺序连续纵向排列；每组内部在可用宽度充足时使用两列，不足时使用一列。较短分组不再预留相邻分组的高度。名称、权限标识、说明与开关保持可读，底部操作区独立于滚动内容。布局保留当前选择，包括已保存但不在当前目录中的权限；不会因为打开或重新排列权限分组而增加权限。

## MCP 范围

API 令牌和 Gate 业务 OAuth 的 MCP 行内编辑均直接提供“不授权”“服务只读”“服务读写”和“指定工具”四项选择。服务只读/读写属于持续授权；服务读写可纳入后续同步的写工具。批选当前全部工具仍属于快照，不表示持续授权。同一条授权对同一服务不能同时使用持续和指定工具模式。

Gate API 令牌的独立范围与 Gate 业务 OAuth 已实现持续授权。后续工具同步后，只要符合已选服务持续范围、本人当前资源权限、功能 scope 和有效 `required_access` 策略，就会自动纳入，无需审核或发布。外部工具默认按写入处理；只有可信本地覆盖或 Gate 自有契约可以确定只读。只读持续策略不会获得写工具。服务身份或本地访问策略变化可能使精确快照失效，需要明确更新；普通工具同步不会为指定工具范围增加 ID。

服务策略绑定 MCP 生命周期身份。删除重建服务或替换信任目标后，不能因为复用相同 ID 或名称而继承旧授权。纯展示更名和保留信任身份的普通升级保留持续意图。API 令牌的指定工具快照也绑定服务身份。工具访问策略、发现、授权和部署保留各自职责。

已有指定工具 OAuth 授权保留原快照。没有策略的旧 API 令牌继续跟随账号资源权限，不伪造调用配额。本人可以明确新建跟随账号的令牌，也可以在跟随账号和独立范围之间双向切换。跟随模式随账号当前及后续资源权限变化，仍受令牌功能 scope 和调用配额限制；空的独立范围不授予业务 MCP 访问。模式切换保留所有者、版本/目录绑定、确认票据和审计校验，不重置该令牌已消耗的频次预算。

外部提供方授权保留现有提供方及本地 allowlist 合同，不提供 MCP 持续授权。单独启用的 `/mcp/manage` 保留固定管理工具与精确目标合同，不订阅业务 MCP。

新建时点击“创建令牌”，编辑时点击“保存授权”。创建、缩权和仅改配额均由这一次操作完成。已有令牌新增功能权限、工具、服务持续范围或服务绑定时，才显示变更明细并要求“确认扩大授权”。明细按 MCP 展示实际变化，变化的功能权限和配额也会列出；返回编辑保留草稿。所有路径仍为同一份草稿取得后台预览和单次确认票据，再提交写入。服务只读/读写切换保留原服务身份，变化后的服务身份仍需明确重新确认。

## 工具发现

列表“工具发现”列可打开对应授权的居中设置弹窗，直接选择“按需发现”或“完整工具列表”。**新旧业务授权均默认按需**；每条 API 令牌、Gate 业务 OAuth 或外部 OAuth 本地授权独立保存。管理资源保留固定工具。按需模式提供七个默认发现/调用/实例会话/回读入口（含 `gate_request_status`），并按配置附加有权固定工具和启用预算后的结果读取入口；完整模式直接列出当前有权工具；两种模式使用相同权限校验，均不扩大授权。

客户端设置只保存名称和接入地址，复制的配置不含 `tool_mode`。旧浏览器中保存的模式会在生成配置时移除。旧 URL 的 `tool_mode` 和 `X-Gate-Tool-Mode` 请求头均忽略，统一采用该授权设置；切换后须刷新客户端工具目录或重新连接。点击一次“保存”，编辑器自动串联本人会话绑定的预览取票与写入，不再显示第二个确认页面；CSRF、版本和原子审计仍保留。结果未知先读取实际状态核对，禁止盲目重放。该设置不修改全局规则或 MCP 客户端插件配置，也不决定 MCP 客户端优先选择哪一个入口。

## 可编辑配额与安全保存

新业务授权默认**每分钟 6000 次、并发 100**。可编辑范围分别为整数 **1–10000** 和 **1–100**。已配置配额的记录回填实际数值，打开编辑器不会写入默认值。旧 API 令牌未设置配额时，编辑器区分当前“未设置”和保存后的拟用值。现有 API 要求每次授权更新均提交具体配额，包括只修改功能权限的情况；编辑器会显示当前值及保存后的拟用值。API 令牌和业务 OAuth 编辑器在支持的范围内允许调高、调低配额，仅改配额可直接保存。旧的只缩小 OAuth 操作保留原合同；修改配额不延长期限，也不扩大 OAuth scopes。

后台预览绑定准确目标、策略变化、工具增减、未来写权限及前后配额，预览本身不授予权限。本人点击“创建”或“保存”后，普通修改自动串联预览和写入；仅扩大已有能力时额外要求一次用户确认。所有写入仍执行当前权限重检、版本/目录/目标绑定、单次确认票据、修订 CAS 和原子脱敏审计。审计失败整体回滚。仅修改配额会保留已失效的指定工具快照与服务绑定，不会重新批准它们。保存结果未知时保留草稿，先读取实际状态后再写入；不能为了找回丢失的明文盲目重复创建。

运行权限取当前账号/资源权限、令牌或授权策略、有效 `required_access` 策略及功能 scope 的交集。Gate OAuth 还取客户端、grant、JWT 和令牌族 scopes 的交集。修改配额不清零已消耗的频次计数。降低并发不取消已派发调用，后续准入使用新上限。业务调用按 API 令牌 ID 或 OAuth grant ID 跨 MCP 共用预算，读取目录不等于执行工具。计数仍限单 Core 进程，进程重启会重置。SQLite 要求单写入者/Core；默认值不表示已测得的吞吐能力。

## 目录与验证限制

API 令牌新建/编辑目录目前支持最多 **5000 个工具、100 个 MCP** 的完整候选响应。新建超限明确失败，不静默截断。当大账号的无关目录超过此界限时，已有小范围令牌可读取有界原范围，返回 `catalog_complete=false`、`scope_editable=false`，仅调整配额。更大规模 API 令牌候选分页尚未实现。独立的 OAuth 分页编辑器每次读取 10 个服务摘要，按服务端搜索，并仅加载正在编辑的 MCP 工具；搜索和翻页保留授权草稿。保存/有效范围继续有界，超限失败关闭。

Console 遵循 [UI 交互约束](ui-interaction-contract.md)：紧凑表格、标签左控件右、可访问的模式单选、不重复页面介绍，异常或帮助按上下文出现。某来源读取失败不能显示成完整空列表。

Gate 在后续请求重新解析授权，并在排队后派发前重检。它不会推送替换客户端工具目录，也不会扩大客户端 OAuth 授权。客户端可能缓存目录，需要主动刷新。真实提供方/ChatGPT 接入、客户端缓存刷新、部署及生产容量需分别验收；源码和合成测试不能证明这些结果。

## 发现偏好保存

工具发现编辑器还可管理最多 20 个固定项及可选纯文本结果预算。发现方式、固定项和预算由一次“保存”统一提交，保留后台版本绑定的预览/确认协议与原子保存；切换模式保留其他草稿字段，目录读取失败不会当成空选择。冲突后先读取已保存状态，再决定是否保存。偏好不改变凭据范围或到期时间。具体限制和分组会话要求见[固定工具与结果预算](on-demand-tools.md#固定工具与结果预算)。
