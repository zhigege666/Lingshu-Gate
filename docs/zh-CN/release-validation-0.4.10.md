# 0.4.10 候选与正式发行验证

[English](../release-validation-0.4.10.md) · [发行指南](releases.md)

## 源码与范围

候选基于 `bc8a920fa1987dfedb8e47ff4c984bd2cd55cd48`，唯一运行时版本来自 `src/lingshu_gate/_version.py`。中英文概述、变更记录、配置指南和双语发行说明同步描述 0.4.10。已有标签（包括 v0.4.8、v0.4.9）不移动。

运行时代码仅修复 Stdio 可选地址为空或纯空白时的规范化。非空地址和 Streamable HTTP 继续执行 URL 校验、私网信任与脱敏规则；编辑器现有无损切换不变。不新增依赖、数据库迁移、权限扩展或默认开启的执行能力。

## 复现与专项检查

2026-10-17 在隔离的原生 Linux 工作目录验证，使用 Python 3.14.4、Node 22.23.2、uv 0.11.33；保留冻结依赖及同步的 pip 导出。这是额外原生主机证据，不能替代工作流的 Python 3.12 源码检查和固定 Python 3.13.15 正式构建。

新增 Stdio 回归在原模型上先复现六项失败。修复后，Stdio、地址安全、Manifest 一致性及私网 HTTP 信任共 117 项通过；包括认证后的 ASGI 预检、创建、读取和编辑，HTTP 空地址拒绝，拒绝编辑后保存摘要不变，以及未认证写入被拒绝。验证了保存不启动进程，未调用用户下游包或生产数据库。

仓库身份、PNG 来源证明边界和授权发现共 61 项通过。前端 78 个文件的 478 项测试、TypeScript/UX 检查及两套生产构建通过；Ruff 通过，Mypy 检查 165 个源码文件无问题，冻结 pip 导出与 `requirements.lock` 一致。

首次全量测试发现两项既有外部配置测试仍假设 MCP 默认直接发现；在未修改的 0.4.9 源码上也复现失败。测试现通过真实本人预览/确认选择直接发现，或使用默认按需的描述/调用流程并绑定返回的 Schema 修订。七项定向检查通过，包括默认模式直接工具名被拒绝且不写入。未放宽运行时发现、授权或请求级覆盖限制。专项组存在重叠，不能相加充当全量测试总数。

另外四项旧协议测试在原始 0.4.9 上同样失败，其模拟访问存储缺少当前 `dispatch_guard` 参数和权限复核方法。测试桩现执行派发前复核；三个旧协议版本验证复核确实运行，新增负例保证复核失败不调用工具。该文件 13 项通过。合并验证外部配置、网关、旧协议、授权发现与 Stdio 后，179 项测试及 2 项子测试通过；仅更新测试契约，未修改网关安全规则。

后续现代协议与 SDK 测试桩同样补齐派发复核；OAuth/日志测试使用已持久化的发现设置与真实目录接线，仍核对原授权范围、不可见工具及全局日志不泄露。该组 48 项和 15 项子测试通过。首次全量记录为 56 项失败、2425 项通过、7 项跳过和 132 项通过的子测试；失败计数含两项子测试。正常冻结依赖同步补齐本机隔离构建环境后，原有 40 项离线 wheel 测试全部通过，未修改或跳过其离线、来源完整性及安全负例。完整最终提交仍由全量回归与工作流检查验收。

源码核对还发现旧浏览器冒烟脚本仍在客户端设置中查找已移除的模式单选框。脚本现分别验证旧浏览器偏好清理，以及真实授权级预览、确认、保存、独立性和不扩权；覆盖中英文和四种既定桌面尺寸。浏览器执行结果须单独核验，不由测试文件存在或类型检查推断。既有浏览器冒烟前移到长时间后端回归之前，保持原超时和全部必需检查，以更早报告界面契约失败。

## 全量与正式发行证据

完整源码和发行验证以对应提交的工作流检查结果为准；以上专项结果不宣称全量测试或正式发布成功。Vite 原有的大分块警告仍属非致命提示，不代表性能验收通过；本补丁不宣称完成浏览器布局或生产部署验收。
