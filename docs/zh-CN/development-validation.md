## 同一 bearer 执行与边界

合成 HTTP 测试经 `/oauth/token` 获取真实签名访问令牌，先只发现 MCP A 并拒绝 B，再以本人私有 Console 会话读取可选范围、预览 A+B 并明确确认。**完全同一个 bearer 随后经 `/mcp` 实际发现并成功调用 B**，正常 HTTP refresh 延续 B。同一用户/客户端的另一 grant 仍仅 A，调用 B 失败。读、写工具均覆盖 2025-11-25 和 2026-07-28 入站协议，使用记录实际派发的隔离安全合成下游。

预览不授予权限，不重签或扩大 JWT/family。另测保留更窄只读令牌族、拒绝缺失 grant scope、新路径移除最后写工具仍保留既有 `tools.invoke` 上限，以及拒绝提高配额/期限。本人/会话/Origin/CSRF、错误身份/资源、当前权限/分类丢失、版本、目标绑定、过期、替换、重放、容量及并发均失败关闭。注入审计失败将授权更新及确认消费一并回滚，恢复后重试仅提交一条更新和一条审计。
