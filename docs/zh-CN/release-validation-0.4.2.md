  一致性和 Compose 语法检查通过。

发行验收要求既有 GitHub 工作流全部原生目标、Compose/离线镜像、校验和、SPDX
及来源证明任务成功。候选检查不代表真实远端 MCP、公开 TLS 或生产升级验收；
合并前仍须精确提交的独立代码/界面复核。下载、SSH 和部署核验属于单独任务。

不能批准信任。生产 SafeNetworkExecutor 仍缺失，本版不扩大授权。
