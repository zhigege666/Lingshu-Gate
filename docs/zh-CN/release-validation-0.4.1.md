- `npm --prefix web test`：66 文件、391 项通过。
- `npm --prefix web run build`：Console 与独立 OAuth 包通过，保留既有大块警告。

- `npm --prefix web run e2e:full`：196 项通过、38 项可选跳过，耗时 6.8 分钟，
  未重试。最终证据包括 52 张登录及 100 张 OAuth 截图，另有两张明确标注的
  可选视觉失败图片。

ASGI 安全测试仅使用合成凭据和临时数据库，覆盖原八个授权字段与额外
`ui_locales`、语言偏好/回退、提示不进入安全票据、完整授权/登录/同意/令牌路径，
以及必要 resource、精确回调、PKCE、未知/重复参数和原查询/字段值/参数数目限制。
无密钥仍可保存关闭状态地址；无活动密钥启用仍被已有后端边界拒绝。

浏览器使用真实构建资源；OAuth 管理/同意 API 全部为受控合成响应，没有生成
真实签名密钥/客户端或接入真实 ChatGPT。覆盖语言提示不改变票据/存储偏好、
保留手动 URL、不自动保存、密钥读取中/失败/重试、模拟密钥操作后重新读取状态，
以及明确启用/关闭确认、可关闭/消退且无秘密的消息和一次性密钥关闭保护。

本人授权覆盖 0/1/1,000 条记录、完整数据筛选后分页、状态/搜索重置、不捏造授权
时间的 UTC 展示、100 MCP/5,000 工具、可搜索只读历史详情、键盘关闭/焦点恢复，
以及明确缩小/撤销确认。写操作仍使用已有本人 API 与版本校验；快速重开确认框
时内容保持在遮罩之上。

中英明暗主题均拍摄 1600×900、1920×1080、2560×1080、2560×1440。登录截图
读取实际合成本地实例健康元数据，失败案例明确模拟元数据；OAuth 截图始终模拟
API。截图证明渲染与交互，不代表外部 OAuth 验收。独立审查以最终源码 HEAD 与
证据为准。

独立审查在中英、明暗主题的 1600×900、1920×1080、2560×1080 复现授权详情

授权详情现使用局部 flex/min-height 约束工具表格内部视口，保留既有搜索、每页
50 行、历史记录与关闭操作；未改授权同意/缩小编辑布局、授权 API 或确认边界。

修正后 16 种尺寸/语言/主题组合的分页均在弹层初始可见区域内，外层溢出为零，
命中检测通过；独立几何截图使用 100 MCP/5,000 工具。本人授权浏览器套件通过
26 项，无重试：点击前检查分页与关闭几何，表格内部滚动时分页保持原位，并覆盖
50 行分页、完整数据搜索与确认。四项新增测试验证旧详情关闭后迟到的剪贴板
成功/失败不会在另一授权详情中显示反馈。

恢复环境通过 Console/OAuth 构建、类型/UI 源码检查、391 项 Console 单元测试、
107 项内置 OAuth 后端测试，以及独立重跑的 16 项配置/授权行为测试。原候选完整

的 CI 与 tag 发布仍须各自核验；PR 包检查不代表发行完成。此次局部修正未宣称

## 剩余边界

首次未筛选浏览器调用在两项可选 `@visual` 重置布局案例失败后停止：宽度 390、
1366 下表格位移为 2 px，断言要求严格小于 2 px。保留失败，未豁免；未运行完整
可选布局/视觉套件，也未更新基线。0.4.0 已记录八项可选失败不新宣称通过。
既有标准完整行为脚本按设计排除 `@visual`。

合成测试不代表真实 ChatGPT/提供方完整兼容、公开 TLS/Cookie/代理、生产升级
或无中断会话已验收；未配置真实凭据、用户代理、SSH 密钥或隧道。生产安全执行器
仍缺失，真实 Git 拉取、代理探测、工具准备和指定网络安装保持关闭式失败。

发布须走既有受保护 main 与发行工作流；五种原生目标、Compose、两个离线镜像、
SPDX、摘要、校验和与全资产来源证明完成并核验后才能称发行完成。须读回发布
标题/正文，与 0.4.1 源码和成对发行说明比对。本源码验证记录不是发布完成证据。
