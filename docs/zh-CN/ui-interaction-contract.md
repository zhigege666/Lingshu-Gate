# UI 交互约束

[English](../ui-interaction-contract.md) · [文档索引](README.md)

本文是新增或迁移 Console UI 及其受影响消费者的验收契约，适用于全部 Console 页面，包括工具、角色权限和调用。它不表示当前全站已经实现这些要求，不要求重写无关页面，也不增加授权或审批流程。

目标是高效完成任务：找到对象、执行预期操作、理解结果并从失败中恢复。除非变更明确涉及相应行为，否则保留现有公共 API、权限、确认边界和请求语义。

## 现有基础

- 保留 React/Vite，以 Ant Design 为主组件基础；不为本约束引入另一套组件库。复用现有 Ajv 和领域校验适配器。专用编辑器或组件预览工具需要解决明确缺口，不是交互修复的前置条件。
- 扩展现有主题入口：[`console-design-provider.tsx`](../../web/src/components/console-design-provider.tsx)、[`index.css`](../../web/src/index.css) 和 [`console-workspace.css`](../../web/src/console-workspace.css) 中的布局规则。不新建竞争性的 token 入口。现有 AntD tokens 与 CSS 变量的收敛必须保护受影响消费者，并作为独立迁移进行。
- 数值以这些文件为依据，不把设计研究中的试验尺寸当作现行标准。例如，当前 AntD provider 定义了 `fontSize: 14`、`borderRadius: 8`、`controlHeight: 36`、`controlHeightSM: 30`；这些只描述 provider，不表示所有现有本地控件都与之相同。修改 token 必须明确提出并检查其消费者。
- 公共组件负责表现与交互机制；领域适配器负责请求、授权、业务状态和秘密处理。行为一致时才复用，不把外观相似的页面封成万能 CRUD 组件。

可编辑控件边界使用 `--input` / AntD `colorBorder`，包括调用页的可空值和仅 JSON 编辑值容器。结构分割线、表格、卡片和只读结果使用较弱的 `--border` / `colorBorderSecondary` / `colorSplit`。两种主题都要保持这些映射一致；焦点和错误指示仍使用各自的语义颜色。修改 token 后，按实际相邻背景检查渲染后的控件。运行后端的版本在登录/注册页品牌页脚及桌面、移动端 Console 固定页眉中保持可见。两处共用认证门禁每次挂载时对既有公开 `/healthz` 元数据的一次独立读取，限时五秒，不带凭据、不缓存、不轮询、不自动重试。加载与失败文案支持中英文；元数据不可用时不使用 Console 构建版本替代，也不阻断认证。无需开放管理 API 或新增公开端点。较长的预发行版本截断时，可在账号菜单中获取完整值，无需悬停，文本在视口内换行。

## 规则

以下规则是本项目的设计决定。参考来源说明其借鉴的方法，不代表整套引入来源项目的规则或框架。

| ID | 验收要求 |
|---|---|
| UI-01 · 页面身份 | 保留一个清晰、可访问的页面身份。允许紧凑或同行标题，保留现有桌面/手机的身份展示安排。不叠加装饰分类标签、同义大标题和重复介绍。必要对象名称和任务说明仍然可见。 |
| UI-02 · 有效空间 | 高度由内容决定。不为布局完整预留空列、等高空面板、占位统计或大等待区。保留必要分组间距和可用的编辑器/日志工作区。区分真正无数据、加载、错误、无权限和未选择状态。 |
| UI-03 · Tokens | 复用现有语义颜色、间距、字体、圆角和层级值。新增任意值应有具体布局理由并接受局部评审。`0`、`auto`、百分比和内容驱动尺寸不自动构成违规。不能暗示已存在 token lint。 |
| UI-04 · 密度 | 同一任务区控件密度一致；长文本和错误允许增加高度。紧凑布局在窄屏和缩放时仍须可读、可点击、操作可达。不为所有内容设置未经验证的统一固定行高。 |
| UI-05 · 表单 | 已知字段用有类型控件，支持的数组用可增删行，合适的映射用键值编辑。标签必须关联输入，placeholder 不替代标签。区分用途、格式/单位帮助和校验。默认单列，强相关短字段适合时可同行。 |
| UI-06 · 校验 | 错误结构包含代码、消息、严重程度、来源、文档路径和草稿版本；可定位文本时附范围。JSON 原文变化时即提供语法诊断；普通必填/格式错误在相应字段被操作后或尝试提交时展示，不在尚未操作的表单上堆满警告。可修复错误在字段旁持续可见，多条或隐藏字段错误提供摘要。摘要动作展开并聚焦字段或 JSON 位置。不只依赖 Tooltip 或临时 Toast。 |
| UI-07 · 表单/JSON | 两种模式自动同步同一语义草稿，不增加需要用户操作的同步/应用步骤，不丢失未展示数据。保留非法原文，绝不以之前的合法值代替提交。保留未知字段、数组顺序及缺失、`null`、`0`、`false`、空字符串的区别。修改区分设置、移除、保持。遵守下文编辑器边界。 |
| UI-08 · 反馈 | 字段错误在字段，区域加载/失败在相应区域，短成功提示用消息，持续任务结果放在任务上下文。持续失败必须有可见恢复入口。同一结果避免重复提示。防止重复提交，明确哪个提交快照拥有响应。 |
| UI-09 · 浮层 | 编辑、只读详情和危险确认分工明确。提供可访问名称、合适的初始焦点、键盘导航和合理的焦点返回。定义 dirty 和 pending 时的关闭行为。长表单操作可达且不遮挡最后字段。能就地完成任务时不新增打断式弹窗。 |
| UI-10 · 列表与表格 | 搜索范围、已应用筛选、加载范围、分页和选择范围真实明确。行主操作使用真正的链接或按钮。高频操作可发现；批量结果保留未解决项的选择并说明部分失败。限量快照不能暗示全服务总量。 |
| UI-11 · 空状态 | 说明真实状态，提供可用下一步，如创建、清除筛选或重试。请求失败不能显示成空集合。上下文已清楚时用紧凑提示，不再增加标题或插画。 |
| UI-12 · 日志与任务 | 区分快照、连接、执行和跟随滚动状态。新记录不能抢走阅读位置。保留来源的真实时间、范围和传输能力；快照不标成实时流。展示组件不能偷偷启动轮询或虚构取消能力。 |
| UI-13 · 可访问性 | 优先原生控件语义、可访问名称、可见焦点和非颜色信息。检查变更任务的键盘路径，包括菜单和浮层。自动可访问性结果不能替代焦点顺序、阅读顺序、缩放和任务完成检查。 |
| UI-14 · 文案 | 领域术语一致，动作标签具体；危险确认说明动作、目标和后果。维护中英文词条、单位和时间含义。诊断标识有助排查且不暴露秘密；原始日志不按界面文案强行翻译。 |
| UI-15 · 复用 | 新复合组件说明真实消费者、支持状态以及交给调用方的职责。显式迁移并检查受影响消费者。采用公共模式时保留工具、角色和调用的最新行为，不平行重建它们的新能力。 |

## 概览与领域边界

仪表盘以紧凑的资源概览开始，不另设一行侧栏已有的导航快捷入口。保留可访问的页面标题和同行口径说明；不提供任务指引的泛帮助弹窗无需保留。Gate 健康状态仅代表 Gate 健康端点，服务状态保留实际含义，工具数量仅覆盖当前用户可见目录。各类资源独立区分加载、失败和成功返回的空结果。资源链接遵循目标页面的权限；展示概览不授予访问权，也不暗示所有可见工具都可调用。

## 编辑器与领域边界

表单/JSON 转换作用于当前文档与版本。表单修改自动更新 JSON 表达，JSON 解析成功后自动更新语义草稿；切换视图不需要额外点击“应用 JSON”或“同步表单”。不能每次输入都格式化原文或移动光标。JSON 语法错误时保留原文、立即提供语法诊断并阻止提交，旧解析结果不能作为回退。切换视图不得丢弃非法原文或用之前的合法值替换它。

校验与错误展示时机分开处理。普通必填/格式错误在字段被操作后或尝试提交时展示，初始空表单不列出全部缺失字段。用户修正已展示错误的字段时重新校验。任何写入或执行前，提交始终校验完整当前草稿，包括未操作和隐藏的字段。必填错误需要完整路径，包括缺失属性；摘要动作展开并聚焦隐藏字段或对应 JSON 位置。原文语法错误立即展示，因为它阻碍对当前文档的可靠解释。

Schema 变化、迟到响应和刷新不得覆盖 dirty 草稿。参数撤销不能恢复旧执行结果。本地同步规则不合并领域中原本独立的保存/应用或确认/发布决定。

键值行中点击“添加”前已经输入的内容也属于草稿，包括只填了键名、尚未填值的情况。它必须参与 dirty 判断和离开保护。保存、运行、切换模式、替换参数或移除其父项时，不能静默忽略或丢弃这些输入：应安全保留，或提示用户先添加或明确清除，并能定位到该行。行级“添加”不代表额外的表单/JSON 同步步骤。

所有会替换编辑上下文的入口采用同一离开决定：弹窗关闭、应用导航、命令导航以及浏览器前进/后退。dirty 表单提供继续编辑或明确放弃；表单提交期间保持编辑器挂载。调用页仍使用其独立提示，说明离开后请求可能继续执行。浏览器文档退出在支持时使用 `beforeunload`，不承诺防护浏览器崩溃。共享退出注册表只保存 dirty/pending 标记，不保存字段值或秘密。

表单只能展示能够安全表达的结构。不支持的 Schema 方言、引用或构造不能被当作校验成功。沿用现有失败关闭路径，给出可处理原因，或在支持时保留 JSON 编辑。JSON 模式不能绕过校验。解析、重复键检测、数字精度保护、结构校验和领域检查是不同能力；不能声称 `JSON.parse` 或 Ajv 自动具备全部能力。

工具参数依工具 Schema。Manifest 编辑依实际项目模型和现有检查；请求中的通用 `dict` Schema 不等于完整 Manifest 表单规范。只读审计、日志和结果 JSON 不因此获得编辑权限。共享编辑器结构不能暗中增加预检请求或改变保存/应用分离行为。

| 领域 | 必须保留的边界 |
|---|---|
| 已有配置的脱敏 endpoint | 显式区分保持/替换。保持脱敏 endpoint 时沿用绑定原配置 ID 的现有保留协议，不把掩码当真实 URL 校验，不回填秘密地址，不取消后端脱敏。替换值必须正常通过 endpoint 校验。新建配置不得接受掩码作为有效 endpoint。该领域保持状态不放宽 UI-07 或 Schema 失败关闭规则。 |
| Manifest 一次性凭据 | `user_credential_values` 不进入可往返 Manifest 和普通撤销/复制/历史。保留提交前移出编辑状态、失败后重新输入的现有语义。 |
| 全局凭据 | 保留失败时现有受控输入生命周期和领域保持/替换语义。不能将掩码当新值提交，也不能由通用错误处理清除所有秘密。 |
| 下游凭据 | 不查询或预填旧秘密。保留成功/关闭时清空以及当前尝试的失败处理行为。 |
| 个人 Token | 完整值仍为仅创建后展示一次的结果，与创建草稿分离；不暗示后续可以重新查询全文。 |
| 临时密码与工具参数 | 保留各自提交/会话生命周期。不能从 Manifest 推导清空或持久化规则。秘密不得进入 URL，也不得自动持久化到浏览器存储。 |
| 执行与导航 | 离开调用页不能被称为取消。按真实会话生命周期定义运行中或实际未保存修改的提醒；不静默重试，不将敏感草稿/结果提升为持久化历史。 |
| 决定与权限 | 保留现有上传、构建、部署、覆盖、启动、取消、放弃、保存/应用、分类确认/发布以及 Token 扩权的独立决定。发现和展示不授予访问权。 |

本地与远端筛选须说明行为。远端查询区分筛选草稿和已应用条件，显示尚未应用的变化；“重置条件”清空草稿并立即查询默认条件；“应用筛选”提交其他草稿修改。本地筛选可以即时作用于已载入记录。这是迁移目标，不表示当前每页已遵守。刷新明确作用范围，不能暗中请求所有页面数据。

## 证据与评审

按变更行为和风险选择适用状态及检查，不要求状态、语言、主题、窗口尺寸的全排列。相关样例包括加载、刷新保留旧数据、无匹配、失败、无权限、dirty、提交中、完成、长内容和窄屏。主题/文案/布局变更需要相应亮暗主题、中英文或缩放证据。

| 层次 | 证明什么 | 当前状态与限制 |
|---|---|---|
| 1. 源码与架构检查 | TypeScript 与现有源码/语言词条契约；新增导入或架构规则须显式实现 | `npm --prefix web run check` 执行类型检查与 `check:ux`。语言词条经 TypeScript AST 检查：两个必需语言对象必须存在、非空，且没有重复或缺失键。其他 UX 规则仍检查源码字符串，包括 `PageHeader` 和帮助入口。在专项变更替换之前保留这些门禁；它们不能证明渲染行为。 |

## 居中弹窗与直接选择 · 2026-10-04

设计负责人：dot。依据用户 2026-10-04 选择设计稿 2 及长期 Gate UI 约束；实现由
工程任务执行，独立视觉与交互验收由 dot 负责。保留现有不冲突规则及授权/草稿保护。

### 适用范围与弹窗骨架

- Gate 新建、编辑、详情等上下文浮层统一使用居中 Dialog。普通路由页面保持页面，
  不自动套用 Admin.NET 或浏览器扩展。现有右侧抽屉逐页迁移，不声称全站完成。
- 配置编辑器默认最大宽度 1200px，宽度不超过视口减 96px；最大高度为视口减
  64px。桌面基线为 1600×900、1920×1080、2560×1080、2560×1440。
- 标题和关闭入口固定顶部，操作栏固定底部，正文仅一个主要滚动容器。JSON 模式
  使用编辑器自身滚动，避免同时存在弹窗正文与编辑器双重纵向滚动。
- 配置编辑框在两种模式下保持这个受限的视口高度，切换表单后 JSON 仍有可用的
  编辑工作区。
- 短字段两列，地址、错误详情、键值列表通栏；大屏不无限拉伸输入框，中英文标签
  留足宽度。表单 / JSON 页签共享同一草稿，不是两个互相复制的独立表单。
- 内容用间距与细分隔线组织，不堆叠卡片。常用字段直接显示，低频高级字段可
  渐进展开。
- 关闭、取消、Escape、点击遮罩及离开遵循统一未保存变更保护；保存中防止重复
  提交和关闭丢失结果。焦点进入弹窗、受控循环，关闭后返回触发控件。

### 选择控件

- 2–5 个固定、互斥且标签简短的选项默认使用原生或具备完整可访问语义的 radio /
  分段单选，一次点击即可选中，不用 Select。
- 筛选需要“全部”时显式提供且默认选中；它是一个单选值，不称“全选”。编辑
  字段遵循实际模型默认值，不机械增加“全部”。
- 6 个以上、动态加载、需检索或标签很长的数据集合可用可搜索选择器。radio 可
  换行，不能仅为省空间偷偷改回 Select。
- 单一布尔值用开关或复选框，多选用复选框。radio 支持方向键、可见焦点、整体
  点击区域和禁用原因，选中状态不能只靠颜色。

### 数据语义

- 启用、运行方式、地址、超时直接可见。当前表单运行方式恰为受管 Stdio、外部
  HTTP、受管 HTTP 三项；advanced 仅是不支持组合的只读状态，不是可选第四项。
- “权限声明”置于高级区，提供只读摘要和 JSON 编辑入口。`permissions` 是声明
  对象，没有 read/write/admin 枚举，不是实际调用授权；实际权限仍由授权页管理。
- 所有表单的 label 与输入在同一行：左侧固定宽度标签，右侧为输入框、radio、
  switch 或 textarea；提示和错误放在控件下方。中英文标签均保持单行。短字段
  双列时，每格内部仍用该布局；窄屏改为单列表单行，不改为上标签下输入。
- 启用不代表立即运行。分别解释保存、应用、连接的真实语义，保存成功不冒充连接
  成功。
- Gate 启动策略与启用独立。两种模式统一显示“Gate 启动时自动启动”；managed
  说明为“自动启动 MCP 进程并连接”，external 说明为“自动建立连接，不启动
  远端进程”。不负责远程进程或操作系统开机自启。
  缺省 `startup_policy` 保留 `legacy_restore`；明确修改开关才采用
  `gate_start_v1`。下次 Gate 进程启动时按 enabled 与 auto_start 一次设置本轮
  意图；手动动作随后控制当前运行，不改变下次启动策略。迁移前说明旧行为。
  不支持的 restart/health
  等值明确报告，禁止静默改变保存含义。
- 未编辑且受 schema 支持的字段保留，不承诺未知字段绕过后端 schema。运行方式
  切换的删除/不兼容影响在操作前说明。
- JSON 非法时保留原文和诊断位置，不用旧表单覆盖。校验结果绑定草稿版本，编辑
  后旧结果失效。

### 预检查与动作

- 仅一份总状态：“检查未通过 · N 个错误”“检查完成 · N 个警告”“检查通过”。
  错误默认展开，字段旁提供精炼原因和处理方法。空“正常/信息”分类不显示，硬
  错误不描述为“不建议”。技术路径和原始原因可渐进展开，重要原因不折叠。
- 点击错误定位字段或 JSON；失败时保存不可用，旁边解释原因。底部“校验配置”为
  次动作，“取消”“保存配置”为标准动作。静态校验不能声称测试了网络连通性。
- 图标使用已有组件库并保持中英文标签；装饰图标 `aria-hidden`。不能仅凭复制文本
  出现 SVG 判定渲染故障。
